## What it is

Watching together should not mean counting down "3, 2, 1, play" over a call. WatchTogether lets people join a room using a short code. When one person plays, pauses or seeks, Socket.IO broadcasts the event so everyone in the room stays in sync.

## Built with

Next.js for the interface, Socket.IO for real-time events and Tailwind CSS for styling.
